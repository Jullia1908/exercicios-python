# Exercícios de Python

Coleção de 38 exercícios desenvolvidos durante o ensino médio para praticar fundamentos de Python e criação de interfaces gráficas simples.

## Organização

- `exercicios-console`: 32 programas executados pelo terminal.
- `exercicios-tkinter`: 6 exercícios de interface gráfica feitos com Tkinter.

Os exercícios trabalham entrada e saída de dados, condições, repetições, listas, funções, cálculos e componentes básicos de interface.

## Como executar

É necessário ter o Python 3 instalado. No terminal, entre na pasta do repositório e execute o arquivo desejado:

```bash
python exercicios-console/ola_mundo.py
```

Para abrir um exercício com interface gráfica:

```bash
python exercicios-tkinter/calculadora_imc.py
```

O Tkinter normalmente acompanha a instalação padrão do Python no Windows.

## Contexto

Este repositório registra minha evolução nos estudos iniciais de programação. Por isso, os arquivos foram mantidos como exercícios independentes e com a estrutura simples utilizada durante o aprendizado.
